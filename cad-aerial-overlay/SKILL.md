# 公路工程 CAD 与航拍套合

先识别图纸上的设计对象和航拍里对应的现场地物，再做配准。让人能看清设计是什么样、现场做到什么程度，同时保留原始图纸和测量数据，方便撤回、复核和继续换图。

## 从交付范围开始

| 用户说法 | 本次工作 | 细则 |
| --- | --- | --- |
| 套图、删除等高线、把航拍套进 CAD | 整理工程图，配准航拍底图，出可编辑 DWG 和全图预览 | [CAD 与航拍套合](references/registration.md) |
| 继续套合、同样要求、换这张底图 | 沿用最近已核验的 CAD 和已确认要求，更新配套底图和预览 | [CAD 与航拍套合](references/registration.md) |
| 中线、路缘、坡顶偏了，见截图箭头 | 逐处辨认要校的地物，只在相关区域修正底图，出前后对比 | [CAD 与航拍套合](references/registration.md) |
| 剩余方量、标高、高差、立体纵断面 | 用原方量和实测高程做带测区定位的汇报图 | [方量与纵断面](references/earthwork.md) |
| 和最早样板一样，做连续航拍视频 | 在原航拍镜头内稳定叠加路线、结构线框和现场标注 | [航拍视频](references/flythrough.md) |

查看当前项目指令、最近交付及用户随后指出的偏差。先找原图、最新 CAD、航拍原片和必要参照，核对图纸版次、路段、可见范围及数据用途。已确认条件直接沿用。涉及本地原件时，遵守当前项目的设备、磁盘和临时文件规则。需要用户做决定时，只问会改变成果的问题，其余部分继续推进。

## 每次交付前核验

1. 确认设计线、实测数据和现状影像各有出处。仅换底或修配准时校正航拍底图，锁定已对齐的桥梁和其他区域。用覆盖对象类型、图层、几何等信息的矢量对照检查工程内容，单看对象数量不足以确认一致。
2. 截图箭头用来定位问题范围。先判断用户指的是中心线、靠坡侧路缘还是坡顶，再用现场可辨地物校横向位置。只有用户给出可核实的同名点依据时，才把点用于配准。遮挡、缺测及确有设计与现状差别的地方如实说明。
3. CAD 出图时核对外参、显示顺序与目标视图，移到独立目录后重开 DWG 并验证出图。汇报图逐页核对数值、引线、标注和缺测。视频先验证短段跟踪与线框稳定性，成片导出后还要实际播放和抽帧检查。
4. 交付时给出主成果、必要配套文件和改动处的对比图。说明适用用途、资料不足的位置和实际做过的验证。无测量控制或仅做局部目视变形的影像，标明供现场或汇报目视对照。

## 后续完善

复用技能后，从用户明确确认的要求和实际验证通过的结果提炼规则。把可跨项目复用的经验写回对应细则，用虚构场景说明公开示例。修订时复核常用情形及曾出错的情形，并在提交记录注明变更依据。
