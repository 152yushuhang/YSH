# CAD 与航拍套合

## 整理工程图

- 找到原 DWG、可用外部参照以及上次已核验的交付。原件只读，用副本处理。先核对模型空间、布局、单位、坐标系或本地坐标、图层和块定义。DWG 外参缺失时定向补齐或标注影响范围，图纸版次或路段不确定时先核对。
- 按用户确认的范围识别等高线和专用高程注记，检查嵌套块及外参里的同类内容。仅要求清除等高线及其专用注记时，保留独立高程点、地物、房屋、图框、纵断面和改路图等原图要素。混合图层应筛对象，核对前后样本，避免整层误删。
- 已有清图成果时，继续套合优先用最近已核验的 DWG。只换航拍时保留工程线、图层、坐标和既有图幅。需要另做方量或标注时用交付副本和独立图层。

## 全局定位和局部复核

1. 识别航拍的可见范围，确认是带定位的正射影像、普通俯拍还是斜拍。坐标系与单位有依据时优先按测量资料定位并用独立检查点验核。普通照片多为局部目视套合，倾斜、起伏和桥面高差都会造成不同区域的位移。
2. 主桥先看两端桥台或桥头、桥面两侧边线和长方向。先定平移、旋转和比例，再复查远端与桥宽。桥面和地面高差较大时分区核对，用多个分散且确实可辨认的特征检查匝道。依据独立复查点和变形表现决定是否使用仿射、同一平面的透视变换或分区变形。拟合点的残差和独立复查结果分开报告，可量化时写明图像尺寸和像素口径。
3. 按地物类型逐段对应设计和现场。

   | 设计对象 | 航拍中优先核查的依据 |
   | --- | --- |
   | 中心线 | 可辨的两侧路缘之间取中，未铺装段按实际可见路床判读。施工车辙只作辅助线索。 |
   | 靠坡侧路面边线 | 碎石路床或成形路面与坡面的分界。检查线是否落在路幅边缘、有没有压到坡面。 |
   | 坡顶 | 坡面上缘实际折线，参考岩土与植被分界以及相邻段形态，分清坡脚、平台、截水沟和挡墙。 |
   | 箭头、圈划 | 用于查找问题段和待核对对象。从截图放大到原航拍以及 CAD 去辨认地物。 |

4. 已确认桥面套合、某段匝道或其他区域后，局部返修使用限域影像变形和平顺过渡。依据可辨地物从上一个可靠版本重做，避免在误改图上反复拉扯。先查错位是否来自投影、施工状态、遮挡或线型认错。若存在真实的设计与现状差别，在汇报中保留这处差别。原片缺失区域留空，遮挡段标待复核，避免把推测画成实测位置。

## 出图和复验

- 图像置于工程矢量下方，使用相对路径关联，DWG 与实际关联的 PNG 或 JPG 同目录交付。检查坐标、插入点、比例、图像边框、打印样式、符号和字体。DWG 或参照不完整时，先交可用预览并如实说明核验状态。
- 用可用的 AutoCAD 或兼容 CAD 回开并实际打印或导出；能运行审计时记录结果。把交付成套复制到独立目录复验，防止图纸仍在读取机器上的原用路径。检查工程矢量的几何、图层等签名，并核对已确认区域在同一底图坐标中的位置。
- 出一张全图预览。返修时附同视角、同范围、同线色的前后局部对比，标清匝道与线型。检查桥端、弯道中线、靠坡侧路缘和外侧坡顶。报告里分别写出已验证位置、目视判断和超出覆盖范围的位置。
