# 航拍视频中的 CAD 线框与标注

当用户说“最早发的那种”时，先找并播放首段样板，抽看开头、中段、结尾。记录镜头怎样沿路线持续推进，设计路线、桥梁梁体和桥墩线框如何随透视变化，桥名、桩号、现场状态分别指向什么。样板的颜色可作参照，实际文字和工程内容以本项目资料为准。

1. 收集原航拍视频、对应路段 CAD、桩号方向、桥型布置或纵断面、桥梁标高或可靠三维模型。检查 DWG 外参及坐标和高程基准。原片过大时保留本地高清源，用代理视频抽帧、跟踪和审片，最终用原片渲染。时间码、裁切和代理比例有变化时，核对代理与原片映射。ChatCut 可用于剪辑和预览，另行完成配准与跟踪。
2. 在原镜头内用稳定地物做多帧跟踪，验证镜头解算及工程几何与实景的对齐。平坦且高差小的区域可先测连续二维贴合的效果。桥面、梁体、桥墩与地面跨越不同高度时，用已核对的相机运动和结构高程或模型，按实际透视投影，检查遮挡关系。使用 CAD 图元保留圆弧和线形，让线条自然连贯。
3. 先输出一个连续航拍试段。用远中近多帧和独立特征叠看设计线位置，并在正常播放速度下查漂移、抖动、折线、突然跳变和遮挡。桩号、桥名及必要的现场说明随各自的工程位置移动，让观众能在同一镜头中看清设计和实景。若用户对照的是连续飞行样板，沿用连续实景叠线的表现方式。定格、分屏和擦除比较属于独立的展示形式，按另行要求制作。
4. 只有单图或二维 CAD，缺结构高程，或跟踪尚未通过检查时，可以交与资料能力相符的定位测试或二维示意，并标明待补的输入与影响。证据不足的桥墩、梁体和高程留待核实。达到连续跟踪、结构依据和样板视觉要求后再作为样板效果交付。
5. 高清导出沿用原片条件及已确认的分辨率和帧率。抽查整段及片头、桥段和结尾，核对播放、线位、标注、遮挡、清晰度和导出参数，并区分已产出的预览与已验收的成片。
