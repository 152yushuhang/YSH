# 剩余挖填方与立体纵断面

1. 从每个测区的方量 DWG 或测量成果核对标高基准、平场标高或正式设计线、三角网、边界、实测日期和剩余挖填方汇总。保留原方量口径和单位，逐区核对数字及合计。中心线高差用于表达沿程情况，剩余方量采用原 DWG 测区汇总或任务指定的正式方量来源。
2. 用户同意按测区里程展示时，从各测区起点 0 m 沿测区中轴取样，平面和纵断面采用同一起点、方向、长度与单位。有正式桩号和中轴依据时按图纸使用。对实测 TIN 覆盖范围作内插，超出覆盖区域留空。高差统一为 `现状标高 − 平场标高`，当来源是正式设计高程线时按对应的设计高程算，并在图中写明口径。
3. 第一页做能直接汇报的航拍总览。标出测区范围、中轴与测区里程。把各区立体纵断面放在对应测区旁边。同色短引线接到测区外缘，避开匝道线、里程和其他标注。小图保留平场标高、代表点高差、区内高差范围、剩余挖方和填方。代表点选在有实测覆盖的位置。若测区仅能按线形目视套合，标注边界为近似位置。
4. 第二页给完整立体斜视纵断面。清楚区分现状标高线、平场标高线和高于或低于平场的区段，保证坐标轴、单位、缺测说明和数据来源可读。高低分区用可区分的颜色，配图例及文字。按前缘曲线读取标高与高差，立体进深注明为示意。
5. 逐页预览，交叉核对图中共用里程点、高差符号、挖填数字和合计。检查每幅小图与测区的对应关系、引线遮挡和缺测留空。按需求交付两页 PDF 和可编辑 DWG 及配套底图。只更新 CAD 航拍时沿用原有方量及纵断面文件。用户仅要求给已有 PDF 换底时，复核套合后保留原实测数据、数值口径和时间，并标明航拍与测量各自的日期。

新任务同时要求刷新旧 PDF，而输入只新增航拍时，按原实测数据更新底图与定位。只有旧 PDF 时可按其已标数据做换底预览，注明原始测量数据待核。需要更新实测标高或方量时，从新测量成果核实数据及口径。
